# Project documentation

These documents explain how the workshop repository and website work.
Participant-facing materials live in `site/downloads/`.

- [Architecture](architecture.md): files, browser behavior, and design choices.
- [Development](development.md): local preview, editing, and checks.
- [Deployment](deployment.md): root-based GitHub Pages publishing and verification.

The root [README](../README.md) is the repository's starting point. Add a README
inside a component folder when it needs its own usage instructions. Add more
architecture documents as real components grow; this static site has no
backend or database to document.
