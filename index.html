Presentation outline

  1. Intro

    Motivating the gap between AI intelligence explosion and human augmentation.

  2. Intro to agent harness

    Chat, files, tools, and computer use. How the agent plans work, launches subagents, and coordinates between chats. Projects, conversations, and context engineering.

  3. Agentic AI vocabulary

    Context, instructions, skills, hooks, tools, and computer use, with local and global examples. See Canva and read-only Google Calendar access in the harness.

  4. Tech vocabulary

    Git, GitHub, VS Code, and Python: what each does and how they fit together, with live examples.

Then: a guided personal planner and an open-ended research problem. The dashboard is an optional extension. Apps stay on localhost; GitHub setup is homework.
