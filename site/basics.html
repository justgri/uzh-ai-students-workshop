Basics

Give an agent a clear workspace, small tasks, and visible checks.

Agent harness
The app around the model that manages files, tools, permissions, and the working session.
Context
Information available to the agent for the current task, drawn from the conversation, instructions, relevant files, and tool results.
Instructions
Project rules loaded by the harness, usually in AGENTS.md or CLAUDE.md.
Skills
Reusable procedures in a folder containing SKILL.md, with supporting files when needed.
Tools
Actions an agent can call, including access to other software. Workshop examples: Canva designs and reading a Google Calendar schedule.
Hooks
Configured actions triggered by events, such as before a tool call. Written instructions alone do not activate them.
Computer use
Working with an app through its screen, mouse, and keyboard. Possible demo: making the workshop poster in MS Paint.
Worklogs
An append-only record of decisions, changes, commands, and observed checks.
Agent handoffs
Saved context for continuing work: current state, evidence, open questions, and the next action.
Documentation
Durable explanations of the project, its structure, how to use it, and how to check it.
