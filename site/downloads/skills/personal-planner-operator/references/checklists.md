# Quick Checklists

## Daily Planning Checklist

- State the reference date, timezone and date windows.
- Confirm at most three daily outcomes fit the user's priorities and available time.
- Give each outcome a concrete tiny step linked to a project ID or project note.
- Keep confirmed deadlines separate from suggested work dates.

## Worklog Checklist

- Record the capture timestamp; include a work time range only if supplied.
- Link the project and identify the source update.
- State what changed and the next step.
- Preserve previous entries, significant shareable verbatim captures and task-movement traces.
- Mark tasks complete only when the update explicitly supports completion.

## Weekly Review Checklist

- Summarize reported wins without inferring completion.
- Identify slips and known causes; leave unknown causes as questions.
- Suggest three to five priorities for the next week, adjusted to available time.
- Carry unfinished tasks forward visibly and link priorities to project notes.
